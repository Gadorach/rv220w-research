# Test-log format

Every test log should begin with:

```text
UTC timestamp:
Researcher:
Board revision:
Device label/asset ID:
Firmware version:
Power supply:
Test equipment:
Probe/adaptor voltage:
Connections:
Commands/actions:
Expected result:
Observed result:
Raw evidence files:
SHA-256:
Conclusion:
Confidence:
Next action:
```

Never replace raw captures with prose summaries. Commit both.
