# Photo evidence

- `original/` — selected original photographs and close-ups retained by the imported package.
- `stitched/` — canonical direct high-resolution board composites.
- `annotated/` — earlier annotation output; use only as a supplemental orientation aid.
- `stitch-records/` — geometric transform/matching records used by the photo-stitch tooling.
- `manifest.json` — image metadata and checksums.

The stitched photographs are the authoritative board layer for future diagrams. They contain no generated board content.
