# RV220W v1.6.2 — bounded UART upload-command hotfix

## Failure corrected

v1.6.1 encoded valid octal data but submitted each append through the general
sentinel wrapper. The complete command exceeded the running OpenWrt console's
practical input-line limit. ash therefore received an incomplete quoted string,
entered its `>` continuation prompt, and never emitted the expected end marker.

## Transport correction

- payload chunks are limited to 24 source bytes;
- each append uses a short `Uxxxxxxxx:<status>` acknowledgement line;
- every emitted command is checked to remain at or below 240 bytes;
- host writes are paced in 32-byte bursts with a short inter-burst delay;
- exact target size, optional SHA-256, and target `sh -n` checks remain;
- the same correction applies to both B53 and MDIO UART upload helpers.

No switch data-register, PHY-control, DSA, reset, image, or flash policy changed.
