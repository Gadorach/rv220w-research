# RV220W v1.7.3 Octeon kernel-patch correction

## Decision

The DSA master lookup failure is fixed in the legacy Octeon Ethernet driver, not in B53 and not in OpenWrt core. The driver already discovers the per-port device-tree node; v1.7.3 exposes that node through the corresponding `net_device`.

A B53 fallback based on `eth0` naming would be RV220W-specific and would violate the normal DSA CPU-master contract. The kernel patch therefore changes only `drivers/staging/octeon/ethernet.c`.

## Build integration

The updater installs the patch once into `target/linux/octeon/patches-6.12/995-rv220w-octeon-dsa-master-node.patch`. DSA builds verify that the installed source-tree patch is byte-identical to the toolkit copy. The build no longer injects or removes a temporary kernel patch.

The DSA DTS remains a temporary build variant and is restored byte-for-byte. Its cleanup runs in a subshell so failed builds cannot lose the backup variable.

## Safety

This remains a RAM-only TFTP validation stage. No flash-writing path is introduced.
