# RV220W v1.3.1 build and RAM boot

## Upgrade an existing v1.3.0 workspace

```fish
cd ~/Downloads/rv220w-openwrt-upgrade-v1.3.0-to-v1.3.1
./upgrade-existing-v1.3.fish \
    --toolkit-dest ~/src/rv220w-research/rv220w-research/promotion-toolkit \
    --workspace ~/src/rv220w-openwrt
```

## Rebuild

```fish
cd ~/src/rv220w-research/rv220w-research/promotion-toolkit
./rv220w.fish build rv220w-initramfs
```

## RAM boot with deterministic defaults

```fish
sudo -v
./rv220w.fish tftp-boot
```

The helper uses `enp0s31f6`, adds `192.168.240.1/24` without removing unrelated addresses, assigns U-Boot `192.168.240.2`, and tries `octeth0`. All U-Boot changes remain RAM-only.
