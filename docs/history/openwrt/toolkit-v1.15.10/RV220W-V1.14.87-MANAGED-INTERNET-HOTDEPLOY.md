Fatal-kernel matching now looks for explicit panic/Oops/b43 error/fatal indications or DMA initialization/mapping/descriptor/engine failures. Normal DMA ring accounting is not an error. `RX: Packet size underrun` is counted as RX telemetry rather than a fatal-kernel condition.

## Internet/DNS gate

`managed-internet` reuses the qualified association + DHCP path. It deliberately does **not** add or replace a default route. After the gateway test passes, it:

1. Refuses to proceed if a pre-existing `1.1.1.1/32` route exists.
2. Adds `1.1.1.1/32` via the DHCP gateway on `rvwsta0`, with the leased WLAN address as source.
3. Sends three interface-bound ICMP probes to `1.1.1.1`.
4. Queries `openwrt.org` explicitly using the DHCP-provided DNS server.
5. Deletes the temporary `/32` route and verifies it is gone.
6. Performs the existing credential/DHCP/supplicant/interface teardown.

No default route, AP mode, arbitrary injection, persistent UCI network state, NVM or NOR write is requested.
