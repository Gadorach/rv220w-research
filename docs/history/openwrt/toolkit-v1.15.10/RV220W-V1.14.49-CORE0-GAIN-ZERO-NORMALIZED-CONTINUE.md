# RV220W v1.14.49 — point-6 zero-normalized gain-search continuation

v1.14.48 corrected the rev<7 `RFSEQCA` routing bitmap to `0x2112`.  The first
hardware run with that correction changed the IQ estimator result from all-zero
raw accumulators to real core-0 energy (`I=22`, `Q=16`, `IQ=-1`).  The signal
path, rotating calibration waveform, TX gain, BCM2056 muxes and RFSEQCA readback
were therefore all live and coherent.

The remaining `-EIO` was introduced by the staged diagnostic, not by Broadcom's
rev5 gain-control state machine.  The stock helper estimates 1024 samples, then
normalizes each I/Q power accumulator with division by 1024 before comparing the
sum to the gain-search threshold.  A low-gain row can therefore contain real raw
energy while normalizing to zero.  Stock treats that result as below threshold
and advances `GAIN_INIT -> GAIN_UP`; it does not abort merely because the
normalized value is zero.

v1.14.49 removes only that intermediate-zero abort.  The estimator math,
threshold, gain table, tone generation, signed TX-power handling, RFSEQCA
`0x2112` correction, BCM2056 setup and rollback surfaces remain unchanged.

For target safety, the diagnostic retains an additional final fail-closed guard:
if the completed search still cannot select a valid non-zero normalized optimum,
point 6 fails instead of proceeding.  A successful point-6 qualification must
also show more than one gain iteration, proving that the gain-search state
machine actually advanced beyond the formerly-fatal first row.

Dedicated RX-IQ coefficient calculation, core 1, RCCAL, normal calibration and
all persistence remain blocked.
