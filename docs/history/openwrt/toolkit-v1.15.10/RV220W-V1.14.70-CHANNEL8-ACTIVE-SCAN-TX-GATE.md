# RV220W v1.14.70 — channel-8 active-scan TX qualification

## Why the boundary can move

The v1.14.69 hardware run closed the passive receive path after the RV220W-specific PCI INT0 correction. b43 was assigned Linux IRQ 109 / Octeon CIU bit 36, the CIU INT0 enable bit was set, host interrupt count rose from 83 to 348, and 267 receive events traversed DMA0 RX_DONE, PIO dispatch, FRAMERDY, DATARDY, header decode, `b43_rx()` and mac80211 with zero b43 drops or PIO/length/FCS errors. The eight-second radiotap capture contained 249 real 802.11 frames, including channel-8 `VertexHotspot` beacons and probe responses. Retained IQ and RCCAL state passed the post-RX verifier.

That makes further passive RX instrumentation lower-value than testing the first normal MAC transmit operation.

## v1.14.70 scope

v1.14.70 changes no kernel, Octeon IRQ or b43 source bytes. It adds a composite host collection gate and target helper command. The collector first repeats the already-qualified CA/channel-8 retained RX-IQ/RCCAL calibration plus passive receive analyzer. Only if that succeeds does it permit one cfg80211 active wildcard scan on 2447 MHz.

The active scan requires `--ack-tx`. Its permitted transmitted traffic is limited to the standard cfg80211/mac80211 probe requests generated by that one scan. The gate does not request authentication, association, an SSID-specific join, AP mode, arbitrary frame injection or user data. It makes no NVM/NOR/persistent write.

## Evidence collected

Before and after the scan the helper records the BCM4322 PCI IRQ, host IRQ count, CN50xx CIU INTx enable/pending snapshot, and the existing b43 debugfs `txstat` ring. The scan output is preserved verbatim and analyzed for BSS entries and channel frequency. Post-scan `iw link` and station dump must prove the interface remains unassociated.

A qualification PASS requires:

- expected MTD-derived WLAN MAC and forced PIO;
- current-boot retained calibration and post-RX verification already present;
- Linux IRQ 109 with CIU PCI INT0 enabled;
- the active scan command succeeds;
- at least one new b43 TX status report exists;
- returned BSS results are on 2447 MHz/channel 8;
- host IRQ count advances;
- no association/station appears;
- no b43 error indication; and
- authentication, AP, arbitrary injection and persistent writes remain blocked.

Until the hardware run passes, this TX boundary is **not hardware-qualified**.
