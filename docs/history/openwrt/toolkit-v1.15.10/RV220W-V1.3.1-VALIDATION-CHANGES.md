# RV220W v1.3.1 validation changes

Version 1.3.0 confirmed the board-specific appended DTB, correct 32 MiB x16 NOR discovery at physical `0x1dc00000`, and seven read-only command-line partitions. It also exposed two remaining DT issues:

1. The UART node retained `clock-frequency = <0>`. Because an appended DTB bypasses the legacy Octeon pruning path that normally fills this property, v1.3.1 sets the verified CN5010 clock explicitly to 400 MHz.
2. Enabling inherited `nor@0,0` caused an unnecessary `physmap-flash 1f400000.nor` probe. v1.3.1 deletes that child while leaving the BootBus parent active, preserving the working Octeon `phys_mapped_flash` setup driven by U-Boot's live CS0 register.

The TFTP helper now adds only `192.168.240.1/24` to the selected interface when requested, leaves unrelated addresses intact, rejects a device/server collision, reports missing positional images precisely, and refuses to continue after stale U-Boot `Abort` or reserved-load-area warnings.

BCM53115 DSA, fixed-link/RGMII timing, GPIO LEDs, reset-button activation, and all flash-writing workflows remain deliberately disabled.
