# RV220W v1.15.5 — pre-artifact_prefix retired manifest compatibility

v1.15.4 correctly stopped requiring the old v1.14.89 component wrappers and
quarantine directory to remain in a modern production workspace. The remaining
edge case was an older genuine legacy manifest created before the
`artifact_prefix` field was introduced.

v1.15.5 keeps current production verification unchanged. It changes only the
manifest-only retired legacy branch:

- exact legacy prefix present: accepted after structural validation;
- `artifact_prefix` absent or empty: accepted as pre-namespace metadata after
  structural validation;
- present non-empty wrong prefix: rejected;
- wrong board/schema/flash/erase/kernel/rootfs geometry: rejected;
- either one-sided legacy wrapper state: still rejected;
- current `wifi-client-persistent` kernel/rootfs/LED/rootfs-content/sysupgrade
  checks remain mandatory.

The retired manifest validator requires RV220W 32 MiB full-NOR geometry, 128 KiB
erase size, kernel at 0x00080000 size 0x00600000, and rootfs at 0x00680000 size
0x01960000.

No OpenWrt source, image, kernel, DTB, package, flash-layout or U-Boot change is
made by this release. Keep the completed v1.15.2 production build and rerun
`./rv220w.fish verify` only.
