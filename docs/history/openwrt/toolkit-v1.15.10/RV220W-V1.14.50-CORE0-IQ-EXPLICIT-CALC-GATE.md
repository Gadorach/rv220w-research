# RV220W v1.14.50 — point-7 core0 IQ explicit-calculation gate

## Qualified predecessor

v1.14.49 qualified point 6/core0 gain control on hardware. The stock rev5 gain-search semantics progressed through three iterations, reached row 5 with normalized selected power 14358, and then hit the requested architecture-resolved cancellation. RFSEQCA `0x2112`, waveform, TX gain, BCM2056 loopback, MAC suspend/resume, sample/IQEST state and coefficient rollback all passed.

## Why point 7 is not just the dormant code

The dormant outer transaction originally called generic `b43_nphy_tx_tone()` and opaque `b43_nphy_calc_rx_iq_comp()` after point 6. Earlier hardware qualification found two target-relevant defects in the generic N-PHY waveform path: I packing and phase/CORDIC stepping. v1.14.50 therefore does not reintroduce that path.

The dedicated point-7 tone reuses `rv220w_rxiq_rev4_tx_tone_packed()`, the exact target-scoped waveform implementation already qualified by point 6.

The coefficient calculation uses the existing diagnostic form of the upstream calculation math. It performs the same 16384-sample IQ estimator and coefficient equations but returns explicit errors and records the final estimator values, calculation error, applied mask and candidate coefficient instead of silently hiding a failed calculation.

## Point-7 telemetry

The debugfs record exports separate fields for:

- dedicated tone return code and sample statistics;
- IQEST command/START completion state;
- final 16384-sample I power, Q power and IQ product;
- calculation error code;
- coefficient applied mask;
- observed candidate core0 `a0/b0` before rollback.

These are separate from the point-6 gain-search telemetry.

## Qualification boundary

The public staged gate now allows fault IDs 1 through 7. `core0-iq` is point 7. A successful point-7 test performs:

1. already-qualified core0 PHY/radio/gain setup and gain search;
2. corrected dedicated core0 calibration waveform;
3. 16384-sample core0 IQ estimate;
4. core0 coefficient calculation and temporary application;
5. candidate coefficient readback;
6. injected `-ECANCELED` at point 7;
7. exact rollback of coefficients, IQEST, sample table, TX power, PHY/radio state, BB config, carrier-search/deaf-count state and MAC resume.

The public gate stops before core1 PHY setup. Core1 gain/IQ processing, RCCAL, normal calibration, scan, association, AP, frame injection, user-data TX and persistent writes remain unreachable.

## Hardware qualification

Build and RAM-boot v1.14.50, keep the qualification AP on channel 8, and run only `core0-iq`. Point 7 is qualified only if the dedicated waveform/estimator/calc telemetry passes, the requested MIPS cancellation is reached, and every rollback gate remains exact.
