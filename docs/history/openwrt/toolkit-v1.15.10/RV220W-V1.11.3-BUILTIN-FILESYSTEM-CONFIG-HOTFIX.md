# RV220W v1.11.3 built-in filesystem config hotfix

## Observed failure

The persistent profile stopped immediately after `make defconfig` with:

```text
Persistent profile requirement was not retained by defconfig: CONFIG_PACKAGE_kmod-fs-jffs2=y
```

The persistent-writer initramfs profile completed successfully.

## Cause

OpenWrt v25.12.5 has JFFS2 and OverlayFS enabled directly in
`target/linux/generic/config-6.12`. It does not define selectable packages named
`kmod-fs-jffs2` or `kmod-fs-overlayfs`. Kconfig therefore correctly discarded
the two nonexistent `CONFIG_PACKAGE_*` seed lines. The v1.11.0 build guard
mistook that expected normalization for a missing filesystem capability.

## Correction

v1.11.3 removes the two invalid package symbols from both persistent seed
configs. Before a persistent build it instead verifies these built-in kernel
requirements in the pinned source tree:

```text
CONFIG_JFFS2_FS=y
CONFIG_OVERLAY_FS=y
CONFIG_MTD_ROOTFS_ROOT_DEV=y
CONFIG_MTD_SPLIT=y
CONFIG_MTD_SPLIT_SQUASHFS_ROOT=y
```

The valid SquashFS package, `fstools`, and `block-mount` requirements remain
checked after `defconfig`.

## Scope

This is a host build-configuration correction only. It does not change the
partition layout, DTS, kernel patch stack, component writer, generated flash
addresses, confirmation tokens, boot-chain bytes, or router state. The already
built persistent-writer ELF remains usable.
