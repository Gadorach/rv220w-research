# RV220W v1.5.2 — robust UART framing hotfix

## Failure corrected

The v1.5.1 helper waited for the end sentinel as a byte substring. When the
OpenWrt console echoed the submitted shell command, the end token appeared in
the echoed command before ash executed it. The collector therefore parsed
shell source text as the command result.

## Corrected protocol

- Every real sentinel is emitted on a fresh line.
- A sentinel is accepted only when it is a complete normalized UART line.
- Parsing walks backward from the last complete end line to the matching
  return-code and begin lines.
- Tokens embedded in echoed input are ignored.
- The protocol works whether terminal echo is enabled or disabled.

The target scanner and its read-only MDIO policy are unchanged. No image
rebuild is required.
