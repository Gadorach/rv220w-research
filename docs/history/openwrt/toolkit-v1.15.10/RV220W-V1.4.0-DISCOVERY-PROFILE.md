# RV220W v1.4.0 read-only discovery profile

## Purpose

This stage adds the tools required for repeatable Ethernet, bridge, MDIO-enumeration, and MTD evidence collection while leaving the hardware-proven v1.3.2 reference build unchanged.

Build modes:

- `rv220w-initramfs`: unchanged v1.3.2 hardware-proven reference profile.
- `rv220w-discovery-initramfs`: additive read-only discovery profile.

## Added packages

The discovery seed selects:

- `ip-full`
- `ip-bridge`
- `ethtool-full`
- `tcpdump-mini`
- `kmod-dsa-b53`
- `kmod-dsa-b53-mdio`
- `kmod-mdio-netlink`
- `mdio-tools`

B53/DSA and MDIO-netlink are available for inspection, but the RV220W DT still has no B53 switch child. Loading a module must not be treated as permission to bind, reset, or configure the BCM53115.

The `mdio` utility supports writes. During this stage use it only to list buses or perform explicitly reviewed read operations. Do not provide a data argument to `raw`, `bench`, or another operation.

## Build and boot

```fish
./rv220w.fish build rv220w-discovery-initramfs
sudo -v
./rv220w.fish tftp-boot --profile discovery
```

The artifact is written to:

```text
~/src/rv220w-openwrt/artifacts/rv220w-openwrt-rv220w-discovery-initramfs.elf
```

## Snapshot collection

After the discovery image reaches OpenWrt and SSH responds:

```fish
./rv220w.fish collect-snapshot no-cable-baseline
```

The target-side script is installed as:

```text
/usr/sbin/rv220w-discovery-snapshot
```

The host helper stores results under:

```text
~/src/rv220w-openwrt/logs/discovery/
```

The snapshot is read-only. It collects full `ip` details, bridge state, ethtool data and counters, MDIO bus enumeration, B53/DSA module availability, MTD geometry, selected device-tree paths, and relevant kernel messages.

## Required discovery gate

Before the physical-jack campaign, collect one `no-cable-baseline` snapshot and one `known-working-jack` snapshot with a cable attached. These are not needed to validate v1.3.2; they establish that the new tools are present and do not disturb the legacy data path.
