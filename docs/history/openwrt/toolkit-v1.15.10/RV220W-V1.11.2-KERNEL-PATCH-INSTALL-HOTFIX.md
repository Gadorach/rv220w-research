# RV220W v1.11.2 kernel-patch install hotfix

## Failure corrected

Toolkit v1.11.1 correctly installed and verified platform v1.5.0, including the
persistent device profiles, but a fresh OpenWrt checkout did not receive the
separate hardware-validated kernel patch files `995` through `999`. The build
preflight correctly refused to continue when patch 995 was absent.

`prepare-sources` was not sufficient because it called the platform installer,
and the v1.11.1 installer managed the base platform patch and persistent image
profiles only. It did not copy the separate DSA/production kernel patch stack.

## v1.11.2 behavior

`./rv220w.fish platform install` now installs or verifies these exact files:

- `995-rv220w-octeon-dsa-master-node.patch`
- `996-octeon-dsa-conduit-length-error.patch`
- `997-b53-multi-conduit-affinity.patch`
- `998-b53-enable-dt-cpu-ports.patch`
- `999-octeon-production-dt-flash-cleanups.patch`

Missing files are copied atomically from the toolkit. Existing byte-identical
files are accepted. Existing differing files are refused and never overwritten.
`platform verify` now includes exact-byte verification of all five files.

Because `prepare-sources` already invokes `platform install`, both existing and
newly cloned source trees are repaired automatically after this hotfix.

## Recovery command

```fish
./rv220w.fish platform install
./rv220w.fish platform verify
./rv220w.fish build persistent
./rv220w.fish build persistent-writer
./rv220w.fish verify
```

No image is written to NOR by this update.
