# RV220W v1.6.1 — decoder-free UART upload hotfix

The v1.6.0 B53 collector correctly established a UART shell but could not upload
its target helper because the running discovery initramfs does not include the
optional BusyBox `base64` applet.

v1.6.1 replaces both B53 and MDIO helper uploads with bounded ash `printf %b`
octal chunks. This requires no target-side decoder. Each chunk must return a
framed zero status. Finalization verifies the exact byte count, runs `/bin/sh -n`,
and compares SHA-256 when `sha256sum` is available.

The switch-access safety policy is unchanged: only pseudo-PHY selector registers
0x10 and 0x11 may be written; switch data registers remain read only. No image
rebuild, DSA binding, reset, or flash write is performed.
