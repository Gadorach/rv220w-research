# RV220W v1.15.0 production persistent Wi-Fi / sysupgrade / WLAN LED

v1.15.0 is the first build-required production successor to the hardware-qualified v1.14.x persistent Wi-Fi candidate.

## Immutable production payload

The `persistent-wifi` build keeps the qualified b43/N-PHY/IRQ109/native-DMA stack but replaces standalone `wpa-supplicant` with full `wpad`, making hostapd and wpa_supplicant available from SquashFS at boot. `luci-app-package-manager` restores LuCI **System → Software**, and `kmod-leds-gpio` supports the reconstructed front-panel WLAN GPIO LED.

The fresh-install UCI default is production-safe: if `/etc/config/wireless` already exists, it is preserved untouched. Only a genuinely fresh install generates defaults, disables the radio, deletes the generated open BSS, commits, and leaves Wi-Fi down.

## WLAN LED

The stock `scm-led.ko` reconstruction identifies WIRELESS as Octeon GPIO4 active-low. The production DTS exposes `rv220w:green:wlan` with the `phy0tpt` default trigger. DIAG/DMZ remain unmapped pending survey evidence.

## Configuration-preserving sysupgrade gate

After `build persistent-wifi` and `verify`, run:

```fish
./rv220w.fish persistent-wifi-stage sysupgrade-preflight
```

This makes fresh raw kernel/rootfs backups and a normal `sysupgrade -b` configuration archive, uploads the candidate, verifies its SHA and requires `sysupgrade -T`. No flash occurs.

Then:

```fish
./rv220w.fish persistent-wifi-stage sysupgrade-install \
    --confirm RV220W_SYSUPGRADE_PRODUCTION_V1150
```

The installer repeats the complete preflight and requires the target-side marker `RV220W_V1150_SYSUPGRADE_DISPATCHED` before an SSH disconnect may be interpreted as the expected reboot.

After a normal NOR reboot, **do not run `reconcile-wpad`**. Run:

```fish
./rv220w.fish persistent-wifi-stage production-postcheck \
    --confirm RV220W_BOOTED_PRODUCTION_SYSUPGRADE_V1150
```

The postcheck requires exact new kernel/SquashFS identity, immutable full-wpad and LuCI package-manager payloads in `/rom`, automatic global hostapd/wpa startup, the preserved enabled AP, a live AP netdev, and `rv220w:green:wlan` with `phy0tpt`.
