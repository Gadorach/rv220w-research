# RV220W v1.13.5 installer hexdump validation hotfix

The v1.13.4 payload itself was correct, but the host-side platform installer
verified obsolete v1.7.3 hexdump substrings after installing the v1.7.4
`platform.sh`. v1.7.4 intentionally moved the input offset and length into
`hexdump -s/-n`, so the old substring could never match.

v1.13.5 updates only the host verifier and adds a regression for the exact
v1.7.4 command forms. OpenWrt platform integration remains v1.7.4. No firmware
layout, image-format, writer, boot-chain, U-Boot environment, or target runtime
code changes are introduced.

A failed v1.13.3-to-v1.13.4 updater run leaves toolkit v1.13.4 installed and the
previous v1.13.3 toolkit in a timestamped backup. The v1.13.4-to-v1.13.5 updater
uses that installed v1.13.4 state, reruns the idempotent platform installation,
and then verifies platform v1.7.4.
