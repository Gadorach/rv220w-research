# RV220W v1.14.82 — normal native-DMA WPA-PSK association

## Hardware basis

v1.14.81 qualified normal b43 64-bit DMA with an ordinary managed scan: DMA selected, zero PIO dispatches, scan rc 0, 11 TX-status completions, IRQ109 progress and two real channel-8 BSS results.

## Change

No kernel or b43 transport patch changes. The Wi-Fi discovery initramfs now includes `wpa_supplicant` and exposes a RAM-only `managed-assoc` test. The host collector prompts for a WPA-PSK without echoing it and streams credentials over SSH stdin. The target creates a private `/tmp` supplicant config, associates one managed interface, records link/station/TX/IRQ evidence, holds the link for five seconds, then stops the daemon and deletes both interface and credential file.

## Boundaries

This release performs WPA-PSK authentication and association only. It does not run DHCP, configure an IP route, start AP mode, inject arbitrary frames, modify UCI network/wireless state persistently, program SPROM/NVM, or write NOR.

## Command

```fish
./rv220w.fish collect-wifi \
    --managed-assoc \
    --ssid VertexHotspot \
    --country CA \
    --ack-rf \
    --ack-calibration \
    --ack-tx \
    --ack-association \
    managed-assoc-dma-v11482
```

The command prompts for the WPA-PSK without echoing it. `RV220W_WIFI_PSK` may be set instead for non-interactive local use; the value is not copied into evidence.
