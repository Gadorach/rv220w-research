# RV220W v1.13.6 host test dependency hotfix

The v1.13.4-to-v1.13.5 updater installed toolkit v1.13.5 and verified OpenWrt
platform v1.7.4 successfully. Its final host regression then failed because two
Python tests called `symlink_to(shutil.which("busybox"))` without checking the
result. CachyOS did not provide a host `busybox` executable, so `shutil.which`
returned `None` and pathlib raised `TypeError`.

BusyBox is not required for the toolkit installation or build workflow. v1.13.6
changes those simulations to use a self-contained Python hexdump shim for the
exact command forms they exercise. Platform v1.7.4,
target runtime code, firmware images, NOR layout, write ordering, boot-chain
protection, U-Boot environment and persistent writer are unchanged.

A failed v1.13.4-to-v1.13.5 run leaves toolkit v1.13.5 active and keeps v1.13.4
in the timestamped backup. The v1.13.5-to-v1.13.6 updater uses that active
v1.13.5 state and reruns the platform install and focused regressions
idempotently.
