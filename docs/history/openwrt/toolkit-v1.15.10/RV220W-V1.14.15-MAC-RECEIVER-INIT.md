# RV220W v1.14.15 — stock WLAN identity and explicit b43 receiver-init gate

## Hardware result carried forward from v1.14.14

The v1.14.14 native-SPROM qualification completed successfully on the RV220W.
The generic `brcm,ssb-sprom` fallback provider was absent, runtime PCI identity
remained the physical `14e4:432b`, SSB registered four cores, and b43 identified
core revision 16 / N-PHY type 4 revision 4 / radio `0x2056` revision 3.

Most importantly, Linux's ordinary `ssb_sprom` sysfs file now contains the
same directly captured second-read image recovered in v1.14.13:

- decoded size: 440 bytes / 220 words;
- SHA-256: `461f3523e65900e1896fc6aa13e9bd551533bcfef042520e0e79acba24d34c61`;
- SPROM revision 8;
- Linux CRC: calculated `0x5a`, stored `0x5a` — PASS;
- SVID/PID: `14e4:432b`;
- board revision: `0x1302`;
- boardflags: `0x00000a00`;
- boardflags2: `0x00000202`;
- TX/RX chain masks: `3/3`;
- FEM2G: `0x0301`.

The paired diagnostic independently reports `matches_second=True`,
`mismatch_second=0`; therefore b43/SSB is consuming the physical calibration
through the hardware-proven double-read path rather than a serialized fallback.

The SPROM's embedded `00:90:4c:d6:00:60` address is not the RV220W operational
WLAN identity. The preserved stock firmware derives the operational WLAN MAC
from the protected platform base MAC plus four. On the qualification unit:

- platform base: `a4:93:4c:b1:42:a6`;
- stock WLAN identity: `a4:93:4c:b1:42:aa`.

## v1.14.15 stage A — identity only, no RF start

`rv220w-wifi-probe apply-stock-mac` reads exactly six bytes from protected NOR
boot-chain offset `0x6ff00`, validates the value, derives base+4, keeps all UCI
radios down, unloads only b43 and reloads it with:

```text
pio=0 macaddr=<derived base+4>
```

No wireless interface is brought up. The helper writes only an ephemeral `/tmp`
marker after verifying the b43 module parameter; it does not alter NOR, SPROM,
PCI configuration or UCI radio-enable state.

Host workflow:

```fish
./rv220w.fish collect-wifi --apply-stock-mac identity-qualification
```

The resulting snapshot must retain native physical SPROM, physical PCI
`14e4:432b`, and show the b43 module MAC equal to the platform base+4 value.

## v1.14.15 stage B — explicit firmware/receiver initialization

The same RAM image exposes a second, deliberately explicit gate:

```fish
./rv220w.fish collect-wifi --receiver-init --country CA --ack-rf receiver-init
```

This operation is not passive: it intentionally invokes the normal mac80211
start path by creating one temporary **managed** interface and bringing it up.
No SSID is configured and the image contains no wpad/hostapd. The helper also
refuses to run if a wireless userspace daemon is detected.

Before starting, both userspace policy and runtime state require:

1. native physical-SPROM calibration integrity is marked qualified;
2. b43's module `macaddr` already equals platform base+4;
3. the operator supplied an uppercase two-letter regulatory country;
4. `--ack-rf` was supplied explicitly.

While the interface is up, the helper captures initialized b43 debugfs
capabilities and kernel firmware messages. It then tears the interface down and
removes it via an EXIT/INT/TERM trap.

The host analyzer requires all of the following:

- module MAC = platform base+4;
- initialized b43 `permanent_mac` = platform base+4;
- temporary interface MAC = platform base+4;
- b43 status `2` (`STARTED`);
- a b43 firmware-version load message;
- N-PHY type/revision and radio identity remain `4/4`, `0x2056` rev3;
- `radio_on=1` during the explicit gate;
- no b43 firmware/error indication;
- target evidence explicitly records that no scan, association, AP or user TX
  operation was requested.

## What remains blocked

v1.14.15 does **not** qualify ordinary RF operation. `passive-scan` is hard
blocked regardless of calibration state. There is no association, AP mode,
supplicant, hostapd or flash/persistent WLAN integration in this stage.

If the receiver-init gate passes on hardware, the next stage can be a separately
reviewed passive-scan/receive test using a constrained Canadian regulatory
setting before any association or AP/transmit qualification.
