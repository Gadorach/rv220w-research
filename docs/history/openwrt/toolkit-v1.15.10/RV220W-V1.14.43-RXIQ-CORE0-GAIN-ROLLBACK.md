# RV220W v1.14.43 — core-0 gain-search rollback qualification

## Qualified baseline

v1.14.42 cross-built and RAM-booted successfully on the RV220W, then passed all five exposed pre-tone injected-cancellation checkpoints on CA channel 8: `carrier`, `tpc-off`, `gain-table`, `core0-phy`, and `core0-radio`. The retained evidence records the architecture-resolved MIPS cancellation value (`-158`), cleanup rc/mask `0`/`0x00000000`, verified MAC suspend/resume, exact before/after IQ equality, no association/stations/persistence, and no enabled-MAC PHY-register readback warnings.

## v1.14.43 scope

v1.14.43 exposes one additional fault point only: `core0-gain` (point 6). Transaction ordering is:

1. already-qualified carrier/TPC/gain-table/core-0 PHY/core-0 radio setup;
2. core-0 `rv220w_rxiq_rev4_gainctrl()`;
3. **fault point 6 — injected cancellation and full rollback**;
4. dedicated RX-IQ tone;
5. `b43_nphy_calc_rx_iq_comp()`;
6. core-1 processing;
7. RCCAL.

The gain-control helper itself uses the internal calibration tone and a 1024-sample IQ estimator while selecting receive gain. Therefore the v1.14.43 test is the first intentionally tone-active/gain-search-active rollback test. The gate cancels before steps 4–7 above.

Normal RX-IQ calibration remains blocked. There is no scan, association, AP mode, frame injection, user-data TX, cache/chanspec/NVM/NOR write, or calibration persistence.

```fish
cd ~/src/rv220w-research/rv220w-research/promotion-toolkit
./rv220w.fish platform verify
./rv220w.fish build wifi-discovery
./rv220w.fish verify
```

## Next hardware run

RAM boot:

```fish
./rv220w.fish tftp-boot \
    --profile wifi-discovery \
    --interface enp0s31f6 \
    --configure-interface
```

Keep the qualification AP on channel 8. After a clean boot, run only the new boundary:

```fish
./rv220w.fish collect-wifi \
    --rxiq-fault-test \
    --country CA \
    --channel 8 \
    --fault-stage core0-gain \
    --ack-rf \
    --ack-calibration \
    rxiq-fault-core0-gain-ch8-v11443
```

A qualified result requires stage/fault ID 6, channel readback 2447 MHz, kernel-published expected cancellation equal to `primary_rc`, cleanup rc 0, cleanup mask 0, verified MAC suspend/resume, exact IQ before/after equality, explicit `requested_internal_cal_tone=1` and `requested_gain_search=1`, explicit `requested_iq_calculation=0` and `requested_rccal=0`, no association/stations/persistence, and no enabled-MAC PHY-register-access warning.

## Do not run normal calibration

Do **not** run `collect-wifi --rxiq-calibration` in v1.14.43. Full RX-IQ coefficient calculation and RCCAL are not yet qualified.
