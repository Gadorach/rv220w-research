# RV220W v1.3.0 RAM-test plan

The test remains TFTP/RAM-only. Do not issue `saveenv`, `erase`, `protect off`,
`cp` to NOR, `mtd write`, or mount any stock flash partition read/write.

## Build and boot

```fish
cd ~/src/rv220w-research/rv220w-research/promotion-toolkit
./rv220w.fish platform install
./rv220w.fish platform verify
./rv220w.fish build rv220w-initramfs
sudo -v
./rv220w.fish tftp-boot
```

The wrapper defaults to the proven direct link and automatically chooses the
board-specific artifact and single FTDI/UART adapter.

## Expected corrections

1. The serial log should no longer contain `clock rate not defined`, `unable to
   open an initial console`, or `failed to set stdio`.
2. `/proc/mtd` should contain the seven read-only command-line partitions.
3. The router LAN should be reachable at `192.168.240.2` from host
   `192.168.240.1` without changing subnets after TFTP.
4. No CompactFlash, LED-display, or generic BootBus timing child should probe.

## Collection block on the router

```sh
mkdir -p /tmp/rv220w-v130
{
    echo '=== BOARD ==='
    ubus call system board
    echo '=== CMDLINE ==='
    cat /proc/cmdline
    echo '=== MTD ==='
    cat /proc/mtd
    ls -l /dev/mtd* 2>/dev/null
    mtdinfo -a 2>/dev/null
    echo '=== IMMUTABLE PARTITION HASHES ==='
    sha256sum /dev/mtd0ro /dev/mtd1ro /dev/mtd2ro 2>/dev/null
    echo '=== SERIAL ==='
    ls -l /dev/console /dev/ttyS* 2>/dev/null
    cat /proc/tty/driver/serial 2>/dev/null
    echo '=== NETWORK ==='
    ip -o link show
    ip -o addr show
    cat /proc/net/dev
    echo '=== DEVICE TREE ==='
    tr -d '\0' </sys/firmware/devicetree/base/model; echo
    tr '\0' '\n' </sys/firmware/devicetree/base/compatible
    for p in uart0 serial0; do
        printf '%s=' "$p"
        tr -d '\0' </sys/firmware/devicetree/base/aliases/$p 2>/dev/null
        echo
    done
    printf 'uart-clock-frequency='
    od -An -tu4 -N4 /sys/firmware/devicetree/base/soc@0/serial@1180000000800/clock-frequency 2>/dev/null
    echo '=== DMESG FILTER ==='
    dmesg | grep -Ei 'uart|serial|console|bootbus|flash|cfi|mtd|compact|pata|fdt|deprecated link|eth[0-2]'
} | tee /tmp/rv220w-v130/validation.txt
```

The raw `/sys/firmware/fdt` copy may still be omitted after Octeon performs
in-place MAC and UART fixups. The unflattened live tree under
`/sys/firmware/devicetree/base` is authoritative for this test.
