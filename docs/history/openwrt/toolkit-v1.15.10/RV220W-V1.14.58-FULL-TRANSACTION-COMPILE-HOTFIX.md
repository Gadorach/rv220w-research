# RV220W v1.14.58 — full-transaction compile hotfix

v1.14.57 introduced the rollback-only natural-completion `full-transaction`
integration gate, but the target build failed while compiling b43 because the
new integration validation referenced `RV220W_RXIQ_GAIN_THRESH`.  The gain
helper's existing threshold constant is named `RV220W_RXIQ_THRESH_PWR` and is
`10000U`.

v1.14.58 changes only that identifier in the integration validation and
advances release/policy telemetry.  It does not alter gain-table data, the
10000 threshold, waveform generation, IQ estimator math, coefficient
calculation, RCCAL sweep/commit behavior, transaction rollback, or RF scope.

The exact v1.14.57 patch is retained as a predecessor fixture.  Normal active
RX-IQ calibration remains blocked.  After build/RAM-boot qualification, run
only the `full-transaction` integration stage on CA channel 8.
