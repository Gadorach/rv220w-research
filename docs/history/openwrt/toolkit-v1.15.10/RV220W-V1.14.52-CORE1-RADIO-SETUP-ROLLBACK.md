# RV220W v1.14.52 — core1 BCM2056 radio setup rollback

## Qualified predecessor

v1.14.51 hardware-qualified fault point 8 (`core1-phy`) on CA channel 8. The transaction retained the already-qualified core0 gain and explicit core0 IQ-calculation gates, entered core1 PHY setup, observed the Broadcom-derived pre-rev7 bitmap `RFSEQCA=0x1221`, reached the MIPS `-ECANCELED=-158` injection, and restored with cleanup rc/mask zero, verified MAC suspend/resume, and exact IQ-coefficient rollback. No core1 radio write occurred in that test.

## v1.14.52 boundary

v1.14.52 advances exactly one setup boundary to fault point 9 (`core1-radio`). After the qualified core1 PHY setup it executes only the existing parameterized BCM2056r3 2.4-GHz radio setup for core1 RX / opposite core0 TX, captures the live calibration-route registers, and injects cancellation immediately afterward.

For core1 RX the helper selects:

- `B2056_TX0 | B2056_TX_RXIQCAL_TXMUX`
- `B2056_RX1 | B2056_RX_RXIQCAL_RXMUX`
- `B2056_RX1 | B2056_RX_LNAG_TUNE`

The stock rev3 effect requires TXMUX `0x0006`, RXMUX `0x0006`, and LNAG_TUNE bits 4..7 clear. The low and upper unrelated LNAG bits are not hard-coded; qualification uses `(LNAG_TUNE & 0x00f0) == 0`.

## What remains blocked

Point 9 injects `-ECANCELED` before the first core1 gain-control call. Therefore this release does not execute a core1 calibration tone, core1 gain search, core1 coefficient calculation, RCCAL sweep/commit, normal calibration, association, AP operation, frame injection, user-data TX, or persistent writes.

All prior rollback surfaces remain active, including PHY/radio snapshots, IQEST CMD/SAMCNT/WT, TX-power state/tables, N-table17 320-word sample snapshot, coefficients, BBConfig, carrier/deaf state, and MAC suspend/resume verification.

## Hardware qualification

After build and RAM-only TFTP boot, run only:

```fish
./rv220w.fish collect-wifi \
    --rxiq-fault-test \
    --country CA \
    --channel 8 \
    --fault-stage core1-radio \
    --ack-rf \
    --ack-calibration \
    rxiq-fault-core1-radio-ch8-v11452
```

A PASS requires all qualified core0/core1-PHY gates, `core1_phy_rfseqca=0x1221`, core1 TXMUX/RXMUX `0x0006`, LNAG bits 4..7 clear, the architecture-resolved injected cancellation, cleanup rc/mask zero, verified MAC suspend/resume, and exact coefficient rollback.
