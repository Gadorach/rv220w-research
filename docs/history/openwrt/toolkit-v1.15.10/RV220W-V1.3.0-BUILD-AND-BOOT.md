# RV220W v1.3.0 build and RAM boot

## Upgrade an existing v1.2.0 workspace

Use the separate upgrade package or replace the toolkit, then run:

```fish
cd ~/src/rv220w-research/rv220w-research/promotion-toolkit
./rv220w.fish platform install
./rv220w.fish platform verify
./rv220w.fish build rv220w-initramfs
```

## RAM boot with configured defaults

The default configuration matches the proven bench:

- host NIC: `enp0s31f6`
- host TFTP address: `192.168.240.1/24`
- router U-Boot address: `192.168.240.2/24`
- U-Boot Ethernet device: `octeth0`
- UART: automatically selected when only one FTDI/UART adapter is present

```fish
cd ~/src/rv220w-research/rv220w-research/promotion-toolkit
sudo -v
./rv220w.fish tftp-boot
```

An explicit equivalent is:

```fish
./rv220w.fish tftp-boot \
  --interface enp0s31f6 \
  --configure-interface \
  --device-ip 192.168.240.2 \
  --ethact octeth0 \
  --port /dev/serial/by-id/usb-FTDI_FT232R_USB_UART_A50285BI-if00-port0 \
  ~/src/rv220w-openwrt/artifacts/rv220w-openwrt-rv220w-initramfs.elf
```

No `--bootargs` override is needed; the board profile embeds the read-only validation command line.
