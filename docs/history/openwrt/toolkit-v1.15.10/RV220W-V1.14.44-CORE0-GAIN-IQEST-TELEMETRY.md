# RV220W v1.14.44 — core0 gain-control IQ-estimator telemetry and rollback

## Hardware result that motivated this revision

v1.14.43 built and RAM-booted successfully. Its new `core0-gain` (fault point 6) run tuned CA channel 8 successfully and entered the intended internal-tone/gain-search scope, but returned `primary_rc=-EIO` before the requested injected `-ECANCELED`. The existing rollback checks still showed cleanup rc/mask zero, MAC suspend/resume verified, and the RX-IQ tuple unchanged.

The staged gain-control helper has one local `-EIO` branch: selected-core estimator power evaluated to zero after `b43_nphy_rx_iq_est()`. The v1.14.43 evidence cannot distinguish an estimator timeout (which upstream b43 represents by zeroing the estimator result) from a completed estimate whose selected power is actually/rounds to zero.

## v1.14.44 scope

v1.14.44 does not advance beyond fault point 6. It repeats exactly the same core0 internal calibration-tone/gain-search path and still cancels before the dedicated RX-IQ coefficient-calculation tone/calc, core1 processing, RCCAL, cache/chanspec updates, or persistent writes.

Two diagnostic/safety additions are made:

1. **IQ estimator rollback surface.** `B43_NPHY_IQEST_CMD`, `B43_NPHY_IQEST_SAMCNT`, and `B43_NPHY_IQEST_WT` are captured before calibration mutation. A pre-existing START bit fails closed with `-EBUSY`. Cleanup restores and verifies all three values exactly and reports `RV220W_RXIQ_CLEAN_IQEST` on mismatch.
2. **Gain-control telemetry.** The last gain-search iteration records row/direction, signed TX-power index, TX-index helper rc, tone rc, packed RX gain, post-estimator IQEST command/START state, raw per-core I/Q/IQ-product accumulators, selected-core averaged power, iteration count, and an explicit failure-reason code.

The analyzer distinguishes at least:
- `core0-gain-estimator-timeout`: `-EIO`, timeout failure reason, IQEST START still asserted;
- `core0-gain-zero-power`: `-EIO`, zero-power reason, START clear, raw powers all zero;
- `core0-gain-rounded-zero-power`: zero selected computed power with nonzero raw values;
- `core0-gain-control-error`: other point-6 failures.

A point-6 run is qualified only if it reaches the requested `-ECANCELED` injection and all cleanup/MAC/IQ/scope gates pass. Diagnostic classifications remain failures and must not be promoted as successful rollback qualification.

## Safety boundary

Allowed active hardware test: `--rxiq-fault-test --fault-stage core0-gain --country CA --channel 8 --ack-rf --ack-calibration`.

Still blocked:
- normal `--rxiq-calibration`;
- dedicated RX-IQ coefficient-calculation tone and `b43_nphy_calc_rx_iq_comp()`;
- core1 gain/IQ processing;
- RCCAL sweep/commit;
- scan, association, AP, user-data TX, frame injection;
- NVM/MTD/NOR/U-Boot/persistent writes.
