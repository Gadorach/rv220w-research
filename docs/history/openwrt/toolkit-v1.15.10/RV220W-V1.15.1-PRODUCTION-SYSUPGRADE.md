# RV220W v1.15.1 production build/sysupgrade gate

v1.15.1 retains the v1.15.0 production Wi-Fi payload and changes the DTS front-panel LED map. Rebuild `persistent-wifi`, verify the new artifacts, and use the same configuration-preserving production sysupgrade workflow with v1.15.1 acknowledgement tokens.

```fish
./rv220w.fish platform verify
./rv220w.fish build persistent-wifi
./rv220w.fish verify
./rv220w.fish persistent-wifi-stage sysupgrade-preflight
```

After preflight:

```fish
./rv220w.fish persistent-wifi-stage sysupgrade-install \
    --confirm RV220W_SYSUPGRADE_PRODUCTION_V1151
```

After a normal NOR reboot, without running `reconcile-wpad`:

```fish
./rv220w.fish persistent-wifi-stage production-postcheck \
    --confirm RV220W_BOOTED_PRODUCTION_SYSUPGRADE_V1151
```

The postcheck requires immutable full `wpad`, LuCI package manager, preserved AP operation, automatic global wireless daemons, and all four surveyed front-panel GPIO LEDs. GPIO5 must remain excluded.
