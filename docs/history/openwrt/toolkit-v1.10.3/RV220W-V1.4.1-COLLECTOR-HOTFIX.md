# RV220W v1.4.1 discovery collector hotfix

The OpenWrt platform integration remains the hardware-proven v1.3.2 baseline. Toolkit and discovery profile versions are separate.

## Fixed

- OpenSSH 9+ `scp` defaults to SFTP, while the RAM-validation target uses Dropbear and does not provide `/usr/libexec/sftp-server`. The collector now streams files through `ssh` and `cat`.
- RAM boots generate fresh host keys; the collector now uses an isolated null known-hosts store for the direct-link lab target.
- Serial aliases resolving to the same FTDI adapter are deduplicated.
- The discovery build can be invoked as `./rv220w.fish build discovery`.

No OpenWrt platform files, flash contents, MDIO registers, or switch ownership are changed.
