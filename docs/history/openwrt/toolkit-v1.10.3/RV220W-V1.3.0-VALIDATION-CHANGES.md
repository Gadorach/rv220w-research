# RV220W v1.3.0 validation changes

The v1.2.0 board-specific image booted successfully with the appended Cisco RV220W DTB, PCI WLAN enumeration, GPIO, MDIO, I2C, and two active Octeon Ethernet interfaces. Two board-DT omissions were exposed:

1. The Octeon early fixup searches `/aliases/uart0`; v1.2.0 supplied only `serial0`, leaving `clock-frequency` at zero and causing the DesignWare UART probe to fail.
2. The entire BootBus parent was disabled, preventing the CS0 `cfi-flash` child from becoming a platform device, so `/proc/mtd` remained empty.

v1.3.0 adds both `uart0` and `serial0` aliases, enables BootBus solely for the CS0 NOR child, and deletes the unrelated generic board's BootBus timing/display/CompactFlash children. The Octeon flash driver continues to derive base, size, and bank width from the U-Boot-programmed CS0 hardware register. All exposed partitions remain read-only.

The BCM53115 node, reset button, USB, fixed-link details, DSA port map, and GPIO LEDs remain disabled or unspecified pending direct evidence.
