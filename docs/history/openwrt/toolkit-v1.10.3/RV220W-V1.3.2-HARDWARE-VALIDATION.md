# RV220W v1.3.2 hardware validation

Date: 2026-07-25/26 UTC

## Result

The clean OpenWrt v25.12.5 build of the v1.3.2 platform profile passed the repaired-baseline hardware gate.

Validated artifact:

- SHA-256: `07d7dd4542bf4d5864a67de56dcebc600d64bd61c550ecbe2acf0b9412b965c7`
- Size: 15,708,840 bytes (`0x00efb2a8`)
- TFTP source-buffer range: `0x05500000..0x063fb2a8`
- ELF entry: `0xffffffff819c5230`
- Appended DTB size reported by U-Boot: `0x0edc`

Observed gates:

- U-Boot transferred the exact image size through `octeth0` at 1000/full.
- The kernel used the appended device tree and reached normal `ttyS0` console output.
- The 400 MHz UART clock produced `base_baud = 25000000`.
- Octeon legacy BootBus setup found the 32 MiB Macronix device as one x16 CFI chip.
- Seven command-line MTD partitions were created with the intended boundaries.
- `eth0` reached 1000/full and `br-lan` entered forwarding state.
- `eth1` also reported 1000/full after userspace initialization.
- The image remained RAM-only; no saveenv or flash-writing command was issued.

## Expected warnings retained

Two warnings are intentionally not changed in the hardware-proven reference profile:

1. The inherited generic `physmap-flash 1f400000.nor` probe fails because the trigger node has no `bank-width`. The later Octeon legacy BootBus registration succeeds and owns the real 32 MiB `phys_mapped_flash` device. Changing the trigger node before discovery would risk another MTD regression.
2. The legacy Octeon Ethernet path reports `Using deprecated link status - please update your DT`. This path is intentionally retained until the BCM53115 physical-port and CPU/conduit topology is established.

`OF: fdt: not creating /sys/firmware/fdt: CRC check failed` does not prevent use of the live device tree under `/sys/firmware/devicetree/base` and did not block boot.

## Promotion decision

v1.3.2 is now the hardware-proven reference baseline. The next profile must be additive and separate: diagnostic userspace and dormant B53/DSA modules only, with no enabled switch node and no register writes.
