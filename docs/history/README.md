is not the installation guide.

- `openwrt/repository-v1.1.0/` — primary repository docs from the earlier RAM-only, no-LuCI stage.
- `openwrt/toolkit-v1.10.3/` — original v1.10.3 toolkit documents before the later boot-policy and automatic-boot validation was integrated.
- [`2026-08-02-persistent-openwrt-promotion.md`](2026-08-02-persistent-openwrt-promotion.md) — transition record for LuCI, NOR writing, and boot-chain patches.
- Earlier dated files record flash acquisition, parser, photo, and v1.9.0 merge milestones.
- `../../archive/import/` contains the original overlapping document set retained for provenance.
