# Public source index

The canonical machine-readable list is `sources/urls.csv`.

Primary references include:

- Cisco RV220W open-source notice for firmware 1.0.3.x.
- Cisco product retirement page and firmware-release references.
- Cavium OCTEON Plus CN50XX product brief and available hardware-reference-manual mirror.
- Broadcom BCM53115 product page/product brief/data sheet.
- Linux B53 DSA documentation.
- Mainline Linux OCTEON platform and boot-info source.
- OpenWrt Octeon target.
- Macronix, Etron, TI, ICS/IDT, and AME component documentation.
- Independent RV220W board inventories and teardown reports.

Third-party files are deliberately not included. Run `sources/fetch-public-docs.sh` to download selected documents into an ignored local directory.
