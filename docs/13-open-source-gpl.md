# Open-source and GPL research

Cisco published an **Open Source Used In RV220W v1.0.3.x** notice. The notice identifies an older embedded-Linux software base including Linux 2.6.21, BusyBox 1.2.1, GCC 4.1.2, binutils 2.16, glibc 2.4, GDB 6.5, and dnsmasq 2.45.

The notice provides source-request reference:

```text
78EE117C99-17964455
```

A directly downloadable complete corresponding-source archive has not yet been located. A source request remains worthwhile even though the formal offer period may have expired.

See:

- `sources/gpl-source-request.txt`
- `sources/urls.csv`

## Particularly valuable requested material

- exact kernel source and `.config`;
- Cavium SDK/board patches covered by GPL;
- RV220W board files and BootBus timing;
- MTD partition definitions;
- GPIO/LED/button/watchdog code;
- Ethernet MAC and BCM53115 initialization code;
- build system and toolchain configuration;
- GPL-covered kernel modules and scripts.

Proprietary Cisco applications and proprietary Broadcom WLAN components may not be included in corresponding source.
